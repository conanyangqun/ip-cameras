# 人形检测误报优化方案分析

## 背景

当前已使用 YOLO nano ONNX 模型（`yolo26n.onnx`，输入 640，`YOLO_CONF_THRESHOLD = 0.4`），整体误报率低于早期 HOG 方案，但仍存在假阳性。

### 典型案例

yuanzi 摄像头（固定机位、广角/鱼鱼眼镜头）经常在**左下角墙角区域**产生误报：一个长期静止的深色物体（深色袋子/椅子，与红色织物相邻、阴影对比强），框内纹理恰好形成类似人形的边缘特征，置信度超过 0.4 被判为人。

该类误报的共同特点：

- 物体**长期静止**
- 位于**画面边缘**（广角镜头畸变严重的区域）
- 置信度不高（通常刚过阈值）

以下方案按性价比排序，方案之间可叠加使用。

## 方案 1：提高置信度阈值（可能一步到位）

`YOLO_CONF_THRESHOLD = 0.4` 偏宽松。

### 实现要点

- 先用现存的 `*_detected.jpg` 假阳性样本统计其置信度分布
- 若误报置信度多在 0.4~0.55 区间，把阈值提到 0.55~0.6 即可直接消除，且几乎不增加漏检
- 建议把阈值做成 `cameras.json` 中的**每摄像头配置项**，而不是全局常量——yuanzi 需要更严的阈值，其他摄像头可以保持宽松

### 局限

- 阈值过高会增加漏检，需结合实际误报样本分布确定
- 无法消除高置信度的误报

## 方案 2：检测区域（ROI）过滤

固定机位 + 固定误报区域，ROI 是标准解法。

### 实现要点

- 在 `cameras.json` 中为每个摄像头增加 ROI 多边形或"排除区"配置
- 判据可用检测框中心点是否落在 ROI 内，或框与 ROI 的重叠比例
- yuanzi 把左下角墙角排除掉即可

### 附带收益

- 广角镜头边缘畸变最严重，人形在边缘区域本来就严重变形，排除后对真人检测影响很小

## 方案 3：时间维度多帧确认（零成本）

当前单帧检出即视为 motion 并可能触发通知。

### 实现要点

- 连续 2~3 帧（约 6~9 秒）都检出、且位置相近才告警
- 在 `process_camera` 里维护 `consecutive_motion` 计数器即可
- 单帧孤立的误报可以直接过滤掉

### 代价

- 告警延迟增加几秒（N=2 时约 6 秒）
- 配合现有的 `notify_cooldown`，误报通知会大幅减少

## 方案 4：静止目标抑制（背景差分交叉验证）

典型案例中的误报物体是**长期不动**的。

### 实现要点

- 用 MOG2/KNN 背景建模（`cv2.createBackgroundSubtractorMOG2()`），只有检测框内同时存在运动像素才确认为人
- 静止的袋子/椅子会被背景吸收不再告警，真人进入院子必然运动
- 背景模型对象需挂在摄像头线程内（每个摄像头独立维护），不能做成全局

### 坑

| 问题 | 对策 |
|---|---|
| 真人站定几分钟被背景吸收 | 设置短暂的容忍逻辑（如前景消失后延迟 N 秒才解除） |
| 光线剧变导致整帧被判为前景 | 可设"前景占比 > 0.6 时判定为异常帧并重置模型" |
| 离线批量检测无时序上下文 | 背景模型仅适用于实时抓拍链路 |

## 方案 5：模型与输入的技术优化

无需训练即可尝试的点：

1. **换更大的模型**：`yolo26n`（nano）精度有限，换 `yolo26s` 精度明显更好，速度仍在可接受范围
2. **letterbox 预处理**：当前 `blobFromImage` 是直接拉伸到 640×640，会破坏宽高比（16:9 被压扁），对人形这种长宽比敏感的类别有影响。改为 letterbox（等比缩放+填充）通常能同时降低误报和漏报
3. **输入尺寸**：保持模型输入尺寸与 `YOLO_INPUT_SIZE` 常量一致；若硬件允许，960/1280 输入对小目标人形更准

## 方案 6：负样本微调（长期方案）

- 持续收集 `*_detected.jpg` 中的误报帧，把误报框标注为背景（或标注实际类别 bag/chair）
- 对 nano 模型做少量微调，针对这个固定机位训练几小时即可显著抑制该区域的误报

## 综合建议

优先级：**方案 1 → 方案 2 + 方案 3 → 方案 5 → 方案 4 / 方案 6**。

1. 统计误报置信度分布，调阈值（改动最小，可能一步到位）
2. 加 ROI 排除区 + 多帧确认
3. letterbox 预处理 / 换 s 模型
4. 仍不够再上背景差分或微调

其中 1、2 改动最小，预计能消除这类墙角静止物体的绝大多数误报。
